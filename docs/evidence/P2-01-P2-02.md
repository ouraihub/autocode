## P2-02

- `AgentSession` 增加单调 `generation`。
- 每次启动创建独立 `LaunchContext { chat_id, generation, support }`。
- 新增 `RunSupportLease`，目录 drop 时只删除自己的运行支持目录。
- 旧 generation 的事件、问题和结束回调不能修改当前 generation。
- 支持目录形如 `<data>/agent_support/<chat-id>/<generation>-<uuid>`，不混入原生历史目录。
