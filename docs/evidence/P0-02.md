## 结论

- Pi 与 OMP 可用，可继续 P1 / P2 / P3-02 / P3-03。
- DSH 作为阻塞项记录到 P3-04/P3-06；在本机解除前不勾选相关任务为完成。
- OMP 的版本落后于本机实际 CLI（设计 §1.3 固定为 18.14.2），实施时要以**当前运行行为**为准，更新握手/分片/ask 测试样本。

1. Pi 完整 `--mode rpc` 握手：`get_state`、`get_messages`、`get_commands` 的真实返回结构，特别是 `sessionFile` 字段。

所有采样须使用隔离 session-dir / profile，不污染用户生产会话。
