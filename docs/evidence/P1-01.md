## 契约确认

对照设计 §3：

- **crate 零 GPUI / 零 Harness 依赖**：Cargo.toml 的 `[dependencies]` 均为类型/错误/序列化基础依赖。
- **Secret 不被序列化、Debug 脱敏**：`types::Secret` 没有 `Serialize/Deserialize`，`fmt::Debug` 用 `finish_non_exhaustive()`；`PartialEq` 实现注释说明非常量时间。
- **AuthMode::None vs ApiKey 语义不同**：`validate::provider` 对 `ApiKey` 强制至少一个启用 Key（`ValidationError::ApiKeyMissing`）；`None` 下无 Key 通过（见测试 `auth_none_may_have_no_keys`）。
- **非法关系在边界拒绝**：URL 必须 http/https 且无 query/fragment；端点协议唯一；default_protocol 必须在端点列表；header 名是 HTTP token，禁用 host/content-length/connection/transfer-encoding/authorization/x-api-key/upgrade/proxy-*；header 值禁 CR/LF/NUL、≤2048 字节；模型协议必须是端点协议子集；模型 ID 唯一且非空；`remove_endpoint` 拒绝"模型剩余协议为空"的删除。

## 验证过程中发现并修正的问题

| 症状 | 修正 |
|---|---|
| 10 处 `the trait bound 'Protocol: Ord' is not satisfied`（BTreeSet 需要） | `Protocol` 增加 `PartialOrd, Ord` derive |
| `Secret: serde::Serialize/Deserialize` 未实现 | 从 `EndpointInput` / `HeaderInput` / `KeyInput` / `ProviderInput` 移除 serde derive（它们是内存草稿；凭据持久化走 `CredentialStore`，§5.3） |
| `cannot find derive macro 'Zeroize'` | `crates/model_provider/Cargo.toml` 启用 `zeroize` 的 `derive` feature |
| validate 内部函数 dead_code | `model_provider.rs` `pub use validate::{base_url, provider, remove_endpoint}` 作为 crate 公共 API |
| 测试 `missing_host_is_rejected` 对 `http:///v1` 的预期错误 | `url::Url` 把 `v1` 识别为 host；测试输入改为 `http://`（真正的 empty host） |
